# 素材规格说明 · 输入清洗后 md 的要求

> 给素材提供者（你）：你去找视频/图集/PDF，转成 md 并清洗后，给我之前先对照这份清单。

## 一、你负责的（我不碰）

```
原始素材（视频/图集/PDF）
   ↓ 转写/OCR/解析（上游转写工具任选：视频转写 / MinerU / 其他）
   ↓ 清洗（去噪/纠错听/合并数字/去口语）—— 清洗是上游的事，我不管
清洗后 md
   ↓ 给我
```

## 二、清洗后 md 的硬性要求

| 项 | 要求 | 说明 |
|---|---|---|
| **格式** | `.md`（UTF-8） | 纯文本 markdown，不要 json |
| **内容** | 教学/知识类（非虚构） | 技术教程、知识讲解、课程笔记等 |
| **语言** | 中文为主 | 英文也能处理但「6 件套+费曼」结构为中文教学优化 |
| **大小** | 5KB ~ 50KB | 太小（<5K）不够展开；太大（>50K）需分块，重排时间长 |
| **清洗状态** | **必须已清洗** | 去 ASR 错听（mic→Mac）、合并拆散数字（300 0→3000）、去口语词（嗯/啊/对吧） |
| **结构** | 无严格限制 | 如果是时间轴交错格式（含 `[MM:SS] 🎤` 标记），内部会自动提取语音主体做重排基准；如果是普通段落 md，直接用全文 |

## 三、标注来源（方便我溯源）

如果在整理 md 时能标注来源，请尽量：
- 视频：在开头注明视频标题/链接/时长
- 图集：注明来源/页数
- PDF：注明文档名/章节

非必须，但有更好。

## 四、发给我的方式

直接把 `.md` 文件给我（或告诉我路径），我按工作流走一遍：
`本体重排 → 逐字校对 → gate_check 门禁 → 交付笔记`

### 5.1 PDF/MinerU 源特别注意（实测经验）

MinerU 解析 PDF 会混入**非教学噪音**：ObjectId/UPC 哈希、时间戳日志、数据库客户端回显、截图 OCR 残片、json dump 等。这些会卡死 gate_check 机械对账（数字覆盖率被噪音拉爆）。**处理流程**：

```bash
# 第 0 步：OCR 源前置过滤（详见 orchestration-manual.md）
python -m scripts.filters.ocr_source_filter --chapter <N> --src <章节_clean.md> --out <章节_clean_only.md>
# 第 1 步起：与常规流程一致（gate_check 用 clean_only.md 作对账源）
```

- 过滤规则按章节登记在 `scripts/filters/ocr_source_filter.py` 的 `CHAPTER_RULES`；**新章节需要先补规则**（参照已有章节的 pre/post 结构）。
- 视频转写源（ASR）**不需要**这一步——ASR 噪音形态不同（错听/拆散数字），由清洗环节处理。
