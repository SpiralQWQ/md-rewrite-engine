## 归档规则

- 版本化文档（施工清单 / 验收报告 / 计划 / 交接）在**版本更替后**移入本目录
- 文件名用英文 kebab-case + 版本号，与 `CHANGELOG.md` 版本段对齐
- 归档文档 = 历史快照，**不更新内容**，仅头部加「已归档」标注
- 当前活跃文档保留在 `docs/` 顶层（如 `task-list-v0.3.0.md`、`acceptance-report-v0.3.0.md`）
